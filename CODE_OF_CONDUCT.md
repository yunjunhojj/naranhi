# Code of Conduct

Naranhi is committed to a welcoming, safe, and constructive community.

## Expected behavior

- Be respectful and considerate, including when opinions differ.
- Give actionable feedback about ideas and code rather than people.
- Welcome contributors regardless of experience, identity, background, or ability.
- Protect private information and respect intellectual-property rights.
- Accept responsibility, apologize when appropriate, and learn from mistakes.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, deliberate intimidation, sustained disruption, and publishing another person's private information are not tolerated in project spaces.

## Reporting and enforcement

Report conduct concerns privately to the maintainer through the contact options on their GitHub profile. Do not open a public issue containing sensitive details. The maintainer may remove content, close discussions, reject contributions, or temporarily or permanently restrict participation when necessary.

This code applies to the repository, issue tracker, discussions, pull requests, and other spaces where someone is representing the project.
