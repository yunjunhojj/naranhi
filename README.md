# 나란히

Ollama와 TranslateGemma를 사용하는 Tauri + React 기반 로컬 병렬 번역 에디터입니다. 원문을 왼쪽에 작성하면 문장별 번역이 오른쪽에 나타납니다.

## 프로젝트 목표

나란히의 목표는 영어와 한국어로 읽고 쓰는 과정에서 번역 도구를 오가는 불편을 줄이는 것입니다.

- **로컬 우선:** 원문과 번역문을 외부 번역 서비스로 보내지 않고 이 Mac에서 처리합니다.
- **양방향 번역:** 영어→한국어와 한국어→영어를 같은 화면에서 전환합니다.
- **문장 단위 반응:** 전체 문서가 아니라 새로 작성하거나 변경한 문장만 번역합니다.
- **이미지에서 바로 번역:** 캡처한 이미지를 붙여넣으면 Apple Vision OCR로 텍스트를 추출하고 번역합니다.
- **PDF 텍스트 자동 정리:** PDF에서 복사하며 생긴 강제 줄바꿈과 불필요한 공백을 붙여넣을 때 자연스러운 문단으로 정리합니다.
- **안정적인 작업 상태:** 입력 도중 중단된 번역은 자동으로 다시 대기열에 넣어 `번역 중` 상태에 고착되지 않게 합니다.
- **편집 가능한 결과:** 생성된 번역문을 사용자가 직접 다듬을 수 있습니다.
- **보이는 성능:** 각 문장에 실제 번역 소요 시간을 표시합니다.
- **개인 작업 보존:** 원문, 번역문, 모델 및 언어 설정을 로컬에 자동 저장합니다.

현재 범위는 영어와 한국어의 텍스트 및 캡처 이미지 번역입니다. 클라우드 번역, 공동 편집, 원본 서식을 보존하는 문서 번역 및 다른 언어는 현재 목표에 포함하지 않습니다.

## 사용자 흐름

1. 상단에서 원문 언어와 번역 언어를 선택합니다.
2. 왼쪽 편집기에 영어 또는 한국어를 입력합니다.
3. 입력이 800ms 동안 멈추면 문장을 구분합니다.
4. 번역되지 않았거나 변경된 문장을 순서대로 Ollama에 요청합니다.
5. 오른쪽에서 번역과 소요 시간을 확인하고 필요하면 결과를 직접 수정합니다.

영어와 한국어만 지원하므로 원문 언어를 변경하면 번역 언어는 자동으로 반대 언어로 설정됩니다.

### PDF 텍스트 붙여넣기

PDF에서 복사한 텍스트를 왼쪽 편집기에 붙여넣으면 페이지 폭 때문에 생긴 단일 줄바꿈을 공백으로 바꿉니다. 빈 줄은 실제 문단 구분으로 유지하고, 목록 항목의 줄바꿈도 보존합니다. 여러 공백, 문장부호 앞의 불필요한 공백, 소프트 하이픈도 함께 정리한 뒤 번역을 시작합니다.

### 이미지 번역

1. 번역할 화면이나 문서 영역을 캡처해 클립보드에 복사합니다.
2. 왼쪽 편집기를 클릭하고 `⌘V`로 이미지를 붙여넣습니다.
3. 왼쪽에서 이미지와 OCR 진행 상태를 확인합니다.
4. OCR이 끝나면 추출된 텍스트가 자동으로 문장별 번역 대기열에 들어갑니다.
5. `이미지 / OCR 텍스트` 토글로 원본 이미지와 인식 결과를 전환합니다.

OCR은 선택한 원문 언어를 우선하여 macOS의 Apple Vision 프레임워크에서 처리합니다. 최대 20MB의 클립보드 이미지를 지원하며 이미지나 OCR 텍스트를 외부 OCR 서비스로 전송하지 않습니다. 붙여넣은 이미지는 현재 앱 실행 중에만 유지되고, OCR로 추출된 텍스트와 번역 결과는 기존 문서처럼 자동 저장됩니다.

## 번역 작업 수명주기

```text
입력 → 800ms 대기 → 문장 분리 → 번역 대기 → 번역 중 → 완료 또는 재시도
```

원문이 바뀌어 기존 실행이 무효화되면 진행 중이던 문장도 다음 실행의 번역 대상으로 다시 포함됩니다. 이전 요청의 늦은 응답은 버리고 현재 원문과 일치하는 결과만 화면에 반영합니다.

## 구성

- **React + TypeScript:** 좌우 편집기, 언어 및 모델 설정, 문장별 상태 관리
- **Tauri + Rust:** Ollama 상태 확인과 번역 요청 중계
- **Apple Vision:** 붙여넣은 이미지의 영어·한국어 텍스트를 Mac에서 OCR 처리
- **Ollama:** `127.0.0.1:11434`에서 동작하는 로컬 추론 서버
- **TranslateGemma 12B:** 영어·한국어 번역 모델
- **Intl.Segmenter:** 선택한 원문 언어에 맞는 문장 분리
- **localStorage:** 현재 문서와 설정 자동 저장

브라우저 화면에서 Ollama를 직접 호출하지 않고 Rust 백엔드가 요청을 전달하므로 CORS 설정 없이 로컬 API만 사용합니다.

## 준비 및 실행

1. macOS용 Ollama를 설치하고 실행합니다.
2. 기본 번역 모델을 내려받습니다.

```bash
ollama pull translategemma:12b-it-q4_K_M
```

3. 의존성을 설치하고 개발 모드로 실행합니다.

```bash
npm install
npm run tauri dev
```

## 검증 및 패키징

프런트엔드와 Rust 백엔드를 검사합니다.

```bash
npm run build
(cd src-tauri && cargo fmt --check)
cargo check --manifest-path src-tauri/Cargo.toml
```

macOS 앱을 생성합니다.

```bash
npm run tauri build -- --bundles app
```

생성된 앱은 `src-tauri/target/release/bundle/macos/나란히.app`에 저장됩니다.
